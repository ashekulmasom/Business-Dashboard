1. Admin Sign-in

Repository: · Only the repository owner (a token with write access) can publish data. The token stays in this browser only.

2. Which month are you preparing?

Example: to prepare September’s final report in October, choose “Sep”, then upload September’s files. The site reads the TRX report date to tell which file is this month and which is last month (LMTD).

3. Upload Reports

Upload any reports, in any order, together or on different days. The site identifies each report by its column names (shuffled columns are fine). At the start of the month, upload the RA-DSS Target File first. Daily: latest TRX + REG + UBP. For growth: last month’s TRX report of the same date, once.

📂 Drag files here, or click to choose
You can add many files at once (.xlsx / .xls / .xlsb / .csv)

3b. Market Service Sheet (your own Excel)

Upload any Excel you prepare for market service tracking. Each sheet needs an RA / RA Wallet column (RA-wise sheet) or an Agent Wallet column (agent-wise sheet — matched to RA by the latest TRX report). Number columns are added up by DSO → DSS → DH and shown on the Market Service page with filters and frozen header/first column. Upload the RA-DSS Target File for this month first.

    4. Report Status (data till)

    🎯 Target Settings
    DSS target = number of DSOs × this value. The OM’s SAV-CNT target is taken from the Savings report’s MA Wise sheet when available.

    BZP (A2M + D2C) monthly target — OM (per DH, in Taka)

    Enter the BZP target given by HQ (A2M and D2C combined). Achievement = A2M report TRX_AMT + D2C report D2C_TRX_AMOUNT. If left empty, the A2M target from the target file is used.

    Operation Manager (OM) Names

    The OM’s name is shown in big bold text on the OM score card, DH cards and the OM table.

    DSS Team Names & Login

    Team name is shown on the leaderboards (e.g. CHOWRASTA TIGERS). DSS can log in with their DSS ID (from the target file); optionally enter a wallet number so they can log in with it too. If DSS IDs are not shown, upload this month’s target file once more.

    5. Publish

    Publishing replaces this month’s data files in the GitHub repository (root folder). New numbers appear on the site within 1–2 minutes.

    💬 Inspiring Quotes

    These quotes rotate on every page (a new one every 5 seconds). Write one quote per line. Leave empty to use the built-in quotes.

    🖼️ Photos — DSO · DSS · OM (click to view)

    Photos are shown on the ⭐ TOP ACHIEVERS page (OM & Admin) for whoever is ranked #1 — they change automatically when the ranking changes. Photos come from your Google Form (“Upload Formal Photo”) and are matched by the Login ID written in the form (DSO: RA wallet, DSS: WhatsApp / login number or DSS ID, OM: MA wallet). The background is removed and made white automatically.

    📊 Login Tracking (who logs in, how many times)

    Every DSO, DSS and OM login is recorded with the login ID, employee type, name, DH, date and time (Bangladesh time). The records are kept in a Google Sheet that belongs to you. Download them here as an Excel file with a Summary sheet and a Details sheet.

    One-time setup (5 minutes) — click to see the steps
    1. Open sheets.new in your browser (creates a new Google Sheet). Name it e.g. Achievers Club Logins.
    2. Menu Extensions → Apps Script. Delete everything there and paste the code below. Change CHANGE-ME to a secret word of your choice. Click 💾 Save.
    3. Click Deploy → New deployment → type Web app → Execute as: Me → Who has access: Anyone → Deploy → allow the permissions.
    4. Copy the Web app URL (ends with /exec) into the box above, type the same secret word in “Download key”, and click Save URL & start tracking.
    🧩 Market Service Criteria (additional option — not needed for regular work)

    Add new tracking criteria here or change existing ones. Each criterion counts (or sums) agents matching your conditions, then shows the result by DSO → DSS → DH on the Market Service page. Field prefixes: DTR: = TRX report columns, REG:, UBP:, R78:, B2BID:, X: (other report), CALC: = calculated fields.
